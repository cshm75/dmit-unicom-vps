## 9929、4837、CN2 GIA、CMIN2 到底差在哪

**AS9929（联通精品线路）** 是 4837 的升级版，修得又宽又直，晚高峰稳得多，价格只贵一点点。

**CN2 GIA（电信高端线路）** 是电信自家的 VIP 高速，三网回程都能沾光，延迟和稳定性在第一梯队，价格也在第一梯队。

**CMIN2（移动精品线路）** 是移动方向的优化线路，移动宽带访问延迟特别低。

判断顺序很清楚：**联通用户优先看 9929，预算紧退一档选 4837，电信访客占多数的站再考虑 CN2 GIA，移动用户看 CMIN2。**

## 下单前必须确认的五件事

**第一，首单价和续费价是不是同一个数。** 年付折扣很多只给首期，第二年按原价续。结账页会写清续费金额，别只看第一行的大字。

**第二，用了优惠码的订单能不能退。** 这一条各家差别很大，有的商家正价商品可全额退款，用了优惠码就不给退。DMIT 的退款规则公开资料里没有完整说明，下单前在商品页或工单里问清楚。

**第三，超流量之后怎么处理。** 是停机、限速还是按量扣费，三种结果对建站的人影响完全不同。ByteVirt 是限速到 1Mbps，这个要提前知道。

**第四，IP 被墙能不能免费换。** 有些商家换一次收 50 元，有些给一次免费机会。买之前问一句，比被封了再问强。

**第五，带宽是共享还是保证。** 标称 500Mbps 不等于你任何时候都能跑满。共享带宽下高峰期会掉速，商品页写“保证带宽”的才是独享。

这五条没有一条写在广告语里，但每一条都能决定你用起来顺不顺。

## 常见问题

**联通用户一定要买 9929 吗？**

不一定要，但值得优先考虑。4837 日常够用，价格能便宜一截，风险在晚高峰。如果你的站在晚上八点到十一点是访问高峰，9929 多花的那点钱是买这段时间的稳定性。如果只是白天用的内部工具或者练手机器，4837 完全够。

**9929 和 CN2 GIA 差多少，值不值得加钱？**

日常使用体感差距不大，两者都是精品线路。差距集中在晚高峰的极限表现和带宽上限上。对联通用户来说，9929 走的是联通自家骨干，路径更直接；CN2 GIA 是电信的精品网，三网回程都能沾光，适合电信访客占比高的站。预算敏感选 9929，业务重要、访客三家运营商都多，再上 CN2 GIA。

**400GB 月流量够建站吗？**

看站点类型。纯文字博客、企业官网，每天几百到几千访问量，400GB 够用。图片多、有视频、或者提供下载的站，400GB 很快就会见底。选档之前先估算一下月流量，再决定要不要往上加一档。

**DMIT 的 EB 和 Pro 怎么选？**

EB 是给联通和移动用户的性价比选择，回程 9929 加 CMIN2。Pro 是三网 CN2 GIA，稳定性上限更高，价格也更贵。你的访客如果以联通宽带为主，EB 的线路已经对上了，没必要为用不上的余量付钱。
